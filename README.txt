TAJ Hypermarket Sales Dashboard Android project

This is Android app source, not an already-built APK.
It wraps the mobile dashboard HTML in an Android WebView and supports Android's file picker for Excel uploads.

To build without a computer, upload this ZIP to a GitHub repository using GitHub's mobile website/app, then open Actions and run "Build TAJ Sales APK". Download the artifact named TAJ-Sales-Dashboard-APK. GitHub account and internet access are required.
The dashboard currently loads Excel/chart/PDF JavaScript libraries from CDNs, so internet is required for those libraries. Uploaded data is session-only in the current HTML.
